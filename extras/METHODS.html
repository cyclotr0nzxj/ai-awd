四 抓包方法

方式 A：一键脚本

# 终端 1：服务端
PYTHONPATH=server python3 -m aiawd_server.main --host 127.0.0.1 --port 9000

# 终端 2：抓包（自动检测网卡 + 后台抓 + 按回车停止）
bash captures/capture.sh

# 终端 3：跑演示 / Electron 人工打
PYTHONPATH=server python3 examples/three_clients_demo.py

# 回到终端 2 → 按回车停止抓包

方式 B：手动 tcpdump

# macOS
sudo tcpdump -i lo0 -w captures/aiawd_match.pcap -s 0 'tcp port 9000'

# Linux
sudo tcpdump -i lo -w captures/aiawd_match.pcap -s 0 'tcp port 9000'

# Ctrl+C 停止

Wireshark 分析三步走

  1. Filter: tcp.port == 9000
  2. 右键任意包 → Follow → TCP Stream（看到完整对话）
  3. 观察前 4 字节 = 长度头，后面是 UTF-8 JSON body

详细步骤见 docs/抓包分析指南.md

六 异常演示（加分项）

# 演示：连上后不发 HELLO 直接发 PING → 服务端拒绝
echo '{"v":1,"type":"PING","seq":1,"payload":{}}' | nc 127.0.0.1 9000

七 阶段状态机

LOBBY
大厅
→
PREPARE
准备
→
DEFENSE
加固
→
ATTACK
攻防
→
FINISHED
结束

服务端自动驱动阶段切换，客户端被动接收 PHASE_SYNC 广播。SUBMIT_FLAG_REQ 仅在 ATTACK 阶段有效。

八 消息类型速查（28 种）

类别消息方向
握手HELLO · WELCOMEC→S · S→C
心跳PING · PONGC→S · S→C

比赛START_MATCH_REQ/RES · MATCH_CONFIG · PHASE_SYNC · RANKING_UPDATE双向 + 单播 + 广播
计分SUBMIT_FLAG_REQ/RESC→S · S→C
准备TARGET_READY · AGENT_READYC→S
活动AGENT_ACTIVITYC→S → 广播 EVENT
事件EVENT · ERRORS→所有 · S→C
断开BYE双向
